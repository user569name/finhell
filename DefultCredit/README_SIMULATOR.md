# ФинХелл — экономический симулятор

Учебный симулятор личных финансов: по стартовому капиталу, ежемесячному
взносу, сроку и оценке рисков он собирает портфель и показывает
последовательность инструментов — от резерва и погашения дорогих долгов до
облигаций, акций и защиты капитала перед целью.

Стек тот же, что у основного проекта: **Python 3.11 + FastAPI + Pydantic +
uvicorn**, интерфейс — обычные HTML/CSS/JS без сборщика и дополнительных
зависимостей.

> **Версия 2.** Рядом с этим симулятором работает оптимизатор капитала:
> три уровня риска, 10 000+ путей Монте-Карло, стресс-тесты, сравнения
> «аренда vs покупка» и «досрочное погашение vs инвестирование», AI-объяснения
> и Sber-style интерфейс. Страница — `/optimizer`, API — `/api/v2/*`,
> документация — `docs/CAPITAL_OPTIMIZER.md`. Акции и криптовалюта в v2
> исключены: только вклады, ОФЗ, корпоративные и муниципальные облигации,
> недвижимость и ипотека.

## Что умеет

- **Инструменты:** деньги / накопительный счёт, банковский вклад, ОФЗ,
  корпоративные облигации, акции, золото, недвижимость, криптовалюта.
- **Факторы риска:** рыночный, кредитный, процентный, ликвидности, валютный,
  инфляционный. Есть точечные переопределения риска и доходности по активу.
- **План:** резерв безопасности → погашение дорогих долгов → размещение
  стартового капитала → регулярные инвестиции → де-рискинг перед целью →
  итог.
- **Облигации:** текущая доходность, YTM, Macaulay- и модифицированная
  дюрация, купонный доход, будущая стоимость с реинвестированием, лестница
  облигаций в общем плане.
- **Монте-Карло:** p10 / p50 / p90, вероятность достижения цели, вероятность
  убытка, медианная и p90-просадка, VaR 95, IRR, график траекторий.
- **Сравнение профилей:** консервативный, сбалансированный, агрессивный.
- **Воспроизводимость:** одинаковый `seed` даёт одинаковый результат.

## Запуск

Из корня проекта `C:\Users\User\Desktop\Finhell`:

```powershell
# вариант 1 — напрямую
.\myvenv\Scripts\python.exe .\DefultCredit\simulator.py

# вариант 2 — через uvicorn с автоперезагрузкой
.\myvenv\Scripts\python.exe -m uvicorn DefultCredit.simulator:app --reload --port 8001
```

После запуска:

| Адрес | Назначение |
| --- | --- |
| <http://127.0.0.1:8001/> | веб-интерфейс симулятора |
| <http://127.0.0.1:8001/docs> | Swagger / OpenAPI |
| <http://127.0.0.1:8001/health> | проверка живости |
| <http://127.0.0.1:8001/instruments> | каталог инструментов и факторов риска |

Порт `8001` выбран, чтобы не конфликтовать с основным приложением на
`main.py`.

## API

### `POST /simulate`

Пример запроса:

```json
{
  "initial_capital": 1000000,
  "monthly_contribution": 30000,
  "horizon_months": 60,
  "risk_profile": "balanced",
  "inflation_rate": 0.08,
  "monthly_expenses": 50000,
  "emergency_fund_months": 6,
  "goal_amount": 3000000,
  "risk_factors": {
    "market": 0.5,
    "credit": 0.3,
    "rate": 0.4,
    "liquidity": 0.2,
    "currency": 0.3,
    "inflation": 0.5
  },
  "asset_risk_overrides": { "stocks": 0.6 },
  "return_overrides": { "stocks": 0.18 },
  "debts": [
    {
      "name": "Кредитная карта",
      "balance": 300000,
      "annual_rate": 0.24,
      "monthly_payment": 15000
    }
  ],
  "include_crypto": true,
  "monte_carlo_paths": 800,
  "seed": 42
}
```

PowerShell:

```powershell
$payload = @{
  initial_capital       = 1000000
  monthly_contribution  = 30000
  horizon_months        = 60
  risk_profile          = "balanced"
  inflation_rate        = 0.08
  monthly_expenses      = 50000
  emergency_fund_months = 6
  goal_amount           = 3000000
  debts                 = @(
    @{ name = "Кредитная карта"; balance = 300000; annual_rate = 0.24; monthly_payment = 15000 }
  )
  monte_carlo_paths     = 800
  seed                  = 42
} | ConvertTo-Json -Depth 6

Invoke-RestMethod -Method Post `
  -Uri http://127.0.0.1:8001/simulate `
  -ContentType "application/json; charset=utf-8" `
  -Body $payload
```

Основные поля:

| Поле | Смысл |
| --- | --- |
| `initial_capital` | сколько денег есть сейчас, ₽ |
| `monthly_contribution` | сколько откладывать в месяц, ₽ |
| `horizon_months` | срок плана, месяцев (1–600) |
| `risk_profile` | `conservative`, `balanced` или `aggressive` |
| `inflation_rate` | ожидаемая инфляция в долях, `0.08` = 8% |
| `monthly_expenses` | расходы в месяц — база резерва |
| `emergency_fund_months` | размер резерва в месяцах расходов |
| `goal_amount` | цель по капиталу, необязательно |
| `risk_factors` | шесть факторов риска от 0 до 1 |
| `asset_risk_overrides` | точечный риск по активу, например `{"stocks": 0.8}` |
| `return_overrides` | своя ожидаемая доходность, например `{"gold": 0.09}` |
| `debts` | список долгов: название, остаток, ставка, платёж |
| `include_crypto` | разрешать ли криптовалюту в агрессивных профилях |
| `monte_carlo_paths` | число сценариев, по умолчанию 800 |
| `seed` | зерно генератора для повторяемости |

Ответ содержит:

- `summary` — итоговые p10 / p50 / p90, реальная стоимость, IRR,
  вероятность цели и убытка, просадки, VaR, размер резерва и погашения долга;
- `allocation` — целевые доли и суммы по инструментам;
- `reserve` — параметры резерва;
- `debt_advice` — разбор долгов и экономия на процентах;
- `sequence` — пошаговый план;
- `bond_ladder` — лестница облигаций;
- `projection` — траектории Монте-Карло по месяцам и годам;
- `scenarios` — сравнение трёх риск-профилей;
- `warnings` — предупреждения модели;
- `disclaimer` — дисклеймер.

### `POST /bond/analyze`

Пример:

```json
{
  "face_value": 1000,
  "price": 950,
  "coupon_rate": 0.12,
  "coupons_per_year": 2,
  "years_to_maturity": 5,
  "reinvest_rate": 0.08
}
```

```powershell
$bond = @{
  face_value        = 1000
  price             = 950
  coupon_rate       = 0.12
  coupons_per_year  = 2
  years_to_maturity = 5
  reinvest_rate     = 0.08
} | ConvertTo-Json

Invoke-RestMethod -Method Post `
  -Uri http://127.0.0.1:8001/bond/analyze `
  -ContentType "application/json" `
  -Body $bond
```

Что считается:

- **текущая доходность** — годовой купон / цена покупки;
- **YTM** — доходность к погашению, находится численно (бисекция) по
  денежному потоку купонов и номинала;
- **Macaulay duration** — средневзвешенный срок поступления платежей;
- **модифицированная дюрация** — чувствительность цены к изменению ставки;
- **купонный доход** — сумма всех купонов и выплаты всего;
- **будущая стоимость с реинвестированием** — купоны реинвестируются по
  указанной ставке до погашения.

Допущения: купон фиксированный, погашение по номиналу, без налогов, комиссий,
амортизации и кредитного дефолта.

## Модель

### Инструменты

Доходности и волатильности ниже — **допущения модели**, а не прогноз. Их
можно переопределить в запросе.

| Инструмент | Ожидаемая доходность | Волатильность | Ликвидность |
| --- | ---: | ---: | ---: |
| Деньги / накопительный счёт | 3% | 0.5% | 1.00 |
| Банковский вклад | 15% | 1% | 1.00 |
| ОФЗ | 13.5% | 5.5% | 0.90 |
| Корпоративные облигации | 16.5% | 12% | 0.60 |
| Акции | 20% | 25% | 0.90 |
| Золото | 11% | 17% | 0.80 |
| Недвижимость | 13% | 10% | 0.15 |
| Криптовалюта | 28% | 55% | 0.80 |

Доступность зависит от срока: ОФЗ — от 3 месяцев, корпоративные облигации и
золото — от 12, акции — от 18, криптовалюта — от 24 (и не в консервативном
профиле), недвижимость — от 48 месяцев и при достаточной сумме.

### Риск

Для каждого инструмента заданы нагрузки на шесть факторов. Подверженность
считается как взвешенное среднее нагрузок, затем:

```text
risk = base_risk × (0.75 + 0.50 × exposure) + 0.10 × exposure
volatility = base_volatility × (0.75 + 0.75 × risk)
```

Чем выше факторы риска, тем выше оценка риска и волатильность. Точечный
`asset_risk_overrides` заменяет расчётную оценку риска для актива.

### Портфель

Итоговая доля — смесь базовой стратегии профиля и оценки «реальная доходность
минус штраф за риск». Затем применяются ограничения:

- максимальные доли по профилю и сроку;
- минимальные доли для денег, вклада, ОФЗ и золота при высокой инфляции;
- проверка минимальной суммы входа для недвижимости;
- нормировка долей к 100%.

### Последовательность

1. **Резерв безопасности** — несколько месяцев расходов на вкладе.
2. **Погашение дорогих долгов** — если ставка по долгу выше безрисковой
   доходности и инфляции. При наличии таких долгов сначала формируется
   стартовый резерв (минимум один месяц расходов), затем гасится долг,
   после чего резерв пополняется до полного.
3. **Размещение стартового капитала** — по целевым долям.
4. **Регулярные инвестиции** — ежемесячные взносы, облигации лестницей,
   акции равными долями.
5. **Защита капитала перед целью** — постепенный перевод в вклад и короткие
   инструменты за несколько месяцев до конца срока.
6. **Результат** — медианный капитал и вероятность достижения цели.

### Монте-Карло

- По умолчанию 800 сценариев; каждый месяц доходность актива — это
  ожидаемая месячная доходность плюс случайный шок.
- Общая рыночная компонента связывает активы через их нагрузку на
  рыночный фактор, остальной шум — индивидуальный.
- Считаются p5 / p10 / p50 / p90, среднее, реальная стоимость с поправкой на
  инфляцию, вероятность цели, вероятность убытка (капитал меньше вложенного),
  максимальная просадка, VaR 95 и годовая IRR по медианной траектории.
- `seed` фиксирует генератор: один и тот же запрос воспроизводим.

## Ограничения

Модель не учитывает налоги, комиссии, спреды, проскальзывание, лимиты
страхования вкладов, ипотеку и расходы на содержание недвижимости, обмен
валюты, дефолты эмитентов и индивидуальные ограничения ликвидности.
Корреляции активов заданы упрощённо — только через общий рыночный фактор.
Исторические данные не используются: доходности, волатильности и инфляция —
это параметры сценария.

## Дисклеймер

Симулятор — учебно-аналитический инструмент, а не индивидуальная
инвестиционная рекомендация. Доходности, волатильности и инфляция — это
допущения модели; реальные результаты могут отличаться. Перед сделками
проверяйте актуальные ставки, условия и риски.
